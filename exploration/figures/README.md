# Figures

All generated by `exploration/plots_1_6.py` and `exploration/plots_7_10.py`, read-only,
from the three raw `.mat` files. Every figure states how many cells it contains, labels
axes with units, and marks flagged cells rather than hiding them.

Flag classes are shared across all figures (`exploration/flags.py`, `tables/cell_flags.csv`)
and are distinguished by **both colour and dash pattern**, so nothing depends on colour alone:

| class | style | meaning |
|---|---|---|
| ok | solid, batch colour | nothing known against it |
| censored | red dashed | never reached its own test's termination criterion |
| page_flagged | violet dash-dot | a dataset page names a problem with this channel |
| data_flagged | pink dotted | the data shows an anomaly no page mentions |

Batch identity is a fixed colour: 2017-05-12 blue `#2a78d6`, 2017-06-30 orange `#eb6834`,
2018-04-12 aqua `#1baf7a`. The palette passes the lightness, chroma, colour-vision-deficiency
separation and normal-vision checks on the light surface.

| figure | what it shows |
|---|---|
| `fig01_capacity_fade.png` | Discharge capacity vs cycle, one line per cell, one panel per batch, with the 0.88 Ah line and 2017-06-30's actual 0.825 Ah stop. Points above the axis are drawn as triangles on the top edge, never dropped. |
| `fig02_continuation_junction.png` | The 5 paused-and-resumed cells joined on barcode, whole record and a ±60-cycle zoom on the junction. All five step **down** in capacity, contradicting the page. |
| `fig03_cycle_life_by_policy.png` | Cycle life by batch and policy on a log scale, one marker per cell so within-policy spread is visible; censored cells as lower-bound triangles. |
| `fig04_internal_resistance.png` | IR vs cycle per batch, with the 22 `IR = 0` cycles marked on the axis floor. |
| `fig05_temperature.png` | Tavg and Tmax vs cycle per batch; batch-median Tavg over time (chamber drift); per-cell baseline; temperature rise against the heat each policy implies. |
| `fig06_capacity_artifacts.png` | Per-cycle capacity change with artifacts circled and restart cycles ticked; where artifacts fall; and the evidence that 2017-06-30's is one wall-clock event (r = −0.993). |
| `fig07_voltage_domain.png` | Qdlin and dQ/dV at cycles 10 and 100 and their difference, for a sample per batch. Confirms cycle indexing is aligned and shows ch 46's noise. |
| `fig08_deltaq_vs_cycle_life.png` | log var ΔQ₁₀₀₋₁₀(V) against cycle life, coloured by batch and by policy. No model fitted. |
| `fig09_within_cycle_profiles.png` | V, I and T within one cycle, early and at end of life, with rests and the CV tail marked; and how the CV share grows with age, by policy and batch. |
| `fig10_missing_data_map.png` | Cycles recorded per cell plus a per-cell map of every data-quality indicator. There are no missing values anywhere in the dataset. |
